# 跨标签页操作同步助手 / Cross-Tab Sync Helper

[English README](README.en.md) · [下载安装包](https://github.com/Pain-ENE/cross-tab-sync-helper/releases/latest) · [更新记录](CHANGELOG.md)

在一个标签页操作，让同组的其他标签页跟随。适合重复录入、批量勾选和多页核对。浏览器扩展在本机运行。

## 功能

- **同步组**：选择要联动的标签页。插件可回放点击、输入、滚动、页面跳转等操作，并显示逐页状态和最近一次回放耗时。
- **分窗平铺**：将组内标签页拆成独立窗口。平铺后依次将浏览器窗口提到前台，最后激活主控窗口。
- **字段隔离**：可排除编号、提交按钮等控件，便于各页保留不同内容、逐页提交。
- **配色**：在「同步设置与快捷键」里分别设置界面主题色和副鼠标颜色。可用调色器或输入 HEX 色值，默认雾青色。
- **精确模式**：在常规回放无法触发某些控件时，可尝试启用浏览器调试接口。控件兼容性取决于目标页面。

## 安装

1. 在 Release 的 **Assets** 下载 `cross-tab-sync-helper-v1.8.4.zip`，解压。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。开启开发人员模式。
3. 选择「加载已解压的扩展程序」，打开包含 `manifest.json` 的 `cross-tab-sync-helper` 文件夹。
4. 原来通过解压目录加载的用户，可先用新包覆盖该目录，再在扩展管理页点「重新加载」。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 开启同步 | `Alt+,` |
| 关闭同步 | `Alt+.` |
| 当前标签页加入或退出同步组 | `Alt+Shift+G` |
| 按当前窗口区域平铺 | `Alt+Shift+S` |

弹窗里的「平铺窗口」按当前显示器的可用区域排列。设置为始终置顶的其他应用仍可能遮挡浏览器。

## 试用与验证

打开两个或更多测试页，先勾选加入同步组，再开启同步。轮流操作各页，核对其他页结果与弹窗状态。遇到浏览器冻结、页面载入或控件缺失时，按弹窗反馈检查对应页面。重要表单建议逐页核对后手动提交。

v1.8.4 已通过浏览器 API 模拟回归，包括四窗口顺序、主控焦点、休眠恢复及单页回放失败。真实桌面的遮挡场景仍需在目标机验证。
