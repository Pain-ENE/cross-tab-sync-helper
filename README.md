# 跨标签页操作同步助手（Cross-Tab Sync Helper）

把一个浏览器标签页里的**鼠标点击、键盘输入、滚动和页面跳转**实时同步到你勾选的其他标签页——适合“同一系统、多个页面、只有编号不同”的批量重复操作：批量录入、档案归档、统一勾选、表单填写、逐页核对等。

类似 Xshell 多终端平铺 + 广播输入的体验：**2～9 个标签页可平铺成独立窗口同屏核对，一处操作、全部跟随**。

> 基于 GitHub 开源项目 [aysner/Multi-Tab-Sync](https://github.com/aysner/Multi-Tab-Sync) 修改增强（上游未附带开源许可证，已如实注明来源并保留其权利声明，详见 [LICENSE](LICENSE)）。

## 核心特性

- **一键开关**：`Alt+,`（逗号）开启、`Alt+.`（句号）关闭；每次切换所有页面弹提示条 + 系统通知
- **批量复制**：弹窗一键把当前标签页复制 2/4/6/9 或自定义份数（最多 16），自动加入同步组，免去逐个开页逐个勾选
- **镜像鼠标（Apple 风格）**：其他窗口同步显示一个 Apple 系统绿渐变箭头，实时跟随你的移动、按住与点击（点击带柔光扩散）；**点击/滚动/键盘输入才接管主控**，悬停划过窗口不会误切换——哪个窗口亮着绿色主控光环、且没有绿鼠标，哪个就是主控窗口，多窗平铺时一眼即知当前操作页
- **字段隔离**：点选“编号”等字段加入“不同步”名单，各页内容不同的字段永不互串；无 name/id 的按钮（如“提交”）也能按按钮文字登记——可做到“填写全同步、核对靠平铺、提交逐页手动”
- **多窗口平铺**：勾选的 2～9 个标签页拆成独立窗口自动铺满屏幕，边操作边肉眼核对每页，防止误填被连带提交
- **双向跟随**：没有固定主控页，在哪个页面操作、其他页就跟随，随时切换方向
- **精确模式**：普通合成事件不起作用的老系统，可切换为浏览器调试接口派发真实键鼠
- **安全设计**：密码框/验证码框永不同步；纯本地运行，无任何网络请求
- **防误触设计**：开关默认关闭不自动开启；开启瞬间对“注入前已填写的焦点字段”做守卫，防止迟到的 change 事件把本页编号覆盖到其他页

## 安装（离线安装，无需联网）

适用于 Chromium 内核 ≥ 88 的浏览器：Chrome / Edge / 360 极速浏览器 / 360 安全浏览器 15+（360 安全浏览器 13 及更早版本内核过旧，不支持）。

1. 下载本仓库（Code → Download ZIP）并解压
2. 地址栏打开扩展管理页：Chrome/Edge 为 `chrome://extensions`，360 安全浏览器为 `se://extensions`
3. 打开右上角**开发者模式** → 点击**加载已解压的扩展程序** → 选中解压出的文件夹
4. 建议固定到工具栏

> 360 用户注意：业务页面需使用**极速模式**（Chromium 内核）。IE 兼容模式下任何 Chrome 扩展都无法工作。

## 使用流程（批量重复操作场景，如档案归档、批量录入）

1. 打开一个模板页，用弹窗里的**「复制多份」**一键生成 2～16 份（自动加入同步组；也可逐页打开后点扩展图标勾选，或每页按 `Alt+Shift+A`）
2. 保持开关**关闭**，逐页填好各自不同的编号（或用“字段隔离”把编号框永久隔离）
3. 点**「分窗口并排排列」**把各页平铺同屏
4. 按 `Alt+,` **开启同步**，在任意一个页面操作，其余全部实时跟随
5. 逐窗**核对**无误后逐页手动提交（可先把“提交”按钮也加入隔离名单，防止误点连带）；其他窗口的绿鼠标会实时显示你的鼠标位置，方便边操作边扫一眼各页
6. 一批做完按 `Alt+.` 关闭，进入下一批

## 与上游 Multi-Tab-Sync 的差异

| # | 修改 | 说明 |
|---|---|---|
| 1 | 修复“迟到 change 覆盖编号” | 开启同步前填在编号框、尚未失焦的旧输入，会在开启后第一次点击时被补发 change 广播覆盖所有页面编号。现通过“注入时焦点字段快照”豁免 |
| 2 | 取消“勾选即自动开启” | 原版勾到第 2 个标签页就自动同步，编号没填必然互串；改为只能手动开启 |
| 3 | 新增“字段隔离” | 点选模式把各页内容不同的字段（编号/提交按钮等）加入不同步名单 |
| 4 | 界面全面汉化 | 弹窗、提示、角标、快捷键描述全部中文 |
| 5 | 按钮按文字登记隔离 | 无 name/id 的“提交”按钮也能加入隔离名单 |
| 6 | 平铺容错与尺寸下限 | 单个窗口创建失败不中断整体；小屏/多页更稳 |
| 7 | 快捷键改为 Alt+, / Alt+. | Ctrl+Alt、Ctrl+`、Ctrl+F 键组合被浏览器校验拒载；Ctrl+数字占“切换标签页”；Ctrl+Shift+数字与输入法冲突；Alt+字母被菜单助记处理吞掉——Alt+逗号/句号为唯一全链路实测通过组合 |
| 8 | 切换弹窗提示 | 每次开/关，所有参与页弹提示条 + Windows 系统通知 |
| 9 | 切换状态链路加固 | 消息链驱动（可唤醒空闲 Service Worker）+ 版本号丢弃过期消息 + 注入完成后再广播提示 |
| 10 | 更名（v1.4） | 更名为"跨标签页操作同步助手"，不局限于归档场景 |
| 11 | 新增镜像鼠标（v1.5） | 其他窗口实时显示主控窗口鼠标的位置/按住/点击（绿色箭头+涟漪，与真实鼠标明显区分）；主控页自动跟随，1.5 秒不动自动淡出，弹窗可开关 |
| 12 | 批量复制标签页（v1.6） | 弹窗把当前标签页一键复制 2/4/6/9 或自定义份数（上限 16）并自动加入同步组；不自动开启同步，不打断“先填编号”流程 |
| 13 | 主控即时切换与 Apple 风格重设计（v1.6） | 只有点击/滚动/键盘输入才接管主控，悬停划过平铺窗口不再引起绿鼠标乱闪；主控窗口四边亮绿色主控光环，切换瞬间旧窗口熄灭、新窗口亮起；镜像鼠标按 Apple HIG 重绘：系统绿 #34c759 渐变 + 白描边 + 柔光晕，涟漪改柔光扩散，缓动用 Apple 曲线；提示条与角标配色同步统一 |

## 安全与隐私

- **完全本地运行**：无网络请求、无统计上报、无账号体系，适合内网环境
- 权限说明：“读取和更改所有网站数据”用于向页面注入同步脚本；“debugger”仅在开启精确模式时使用
- 敏感保护：密码框、验证码框、银行卡字段永不被镜像
